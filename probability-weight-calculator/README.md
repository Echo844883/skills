# 目标成功率评估器 (Probability Weight Calculator)

一个纯前端的自我评估小工具：选定目标（考研 / 保研 / 本科就业），勾选你想评估的内容
（如英语六级、学科竞赛、GPA、实习经历……），对每一项打分，工具会：

1. 根据目标自动给各项分配一套经验性权重（并按你实际勾选的项重新归一化到 100%）；
2. 结合权重与自评分算出一个综合「加权分」；
3. 结合你设定的目标竞争难度，把加权分映射成一个成功率百分比；
4. 给出权重分布图表，以及「优势项 / 建议优先提升项」的文字分析。

## 使用方式

纯静态页面，无需构建、无需安装依赖、无需 API Key：

- 直接打开 `index.html` 即可在本地使用；
- 或访问部署好的 GitHub Pages 页面（见仓库根目录 README 中的链接）。

所有计算都在浏览器本地完成，不会上传任何数据。

## 权重模型说明

`data.js` 中的 `GOALS.<goal>.weights` 是每个目标下各评估项的基准权重（合计 100）：

- **考研**：核心是「目标考试复习 / 模拟成绩」（权重最高），其次是 GPA、英语等基础项；
- **保研 / 推免**：GPA 排名、竞赛获奖、科研经历权重最高；
- **本科就业**：实习经历、项目经验权重最高。

用户实际勾选的项（含自定义添加项）会按其基准权重重新归一化到 100%，
再乘以自评分求和得到「加权分」，最后通过一个 sigmoid 曲线（受你设定的
「目标难度」档位影响中点）映射为 1%~99% 的成功率区间，避免给出 0% / 100% 这种
过于绝对的结论。

## 免责声明

这是一个基于经验规则的自我评估辅助工具，**不是**严谨的统计预测模型，
结果仅供参考，不代表真实的录取率 / 通过率 /录用概率。
