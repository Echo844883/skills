# 信标提醒台（Beacon）

`index.html` 是一个完全自包含的单文件网页闹钟：没有任何外部请求，没有构建步骤，
双击就能用。字体走系统字体栈，在访问不到 Google Fonts 的网络里也能正常显示。
三张星空背景以 WebP data URI 内嵌（约 570 KB，整个文件 ~640 KB）。

## 界面

四屏横向翻页（滑动 / 点位轨道 / 键盘左右方向键）：

| 页 | 内容 |
| --- | --- |
| 海报 | 实时钟、轨道动画、待命数量与下一次触发时刻 |
| 授权 | 系统通知、声音与振动、屏幕常亮，三项分别请求 |
| 新建 | 时刻、自定义提醒内容、仅一次 / 每天 / 按星期 |
| 队列 | 待命列表与实时倒计时，可停用、删除、清空 |

到点时全屏响铃层弹出，可「我知道了」或「稍后 10 分钟」。

背景是三张竖构图星空照片，随翻页交叉淡入（海报 → 1、授权 → 2、新建 → 3、队列 → 2）。
海报页让星空全开，只在上下压渐变保住文字；功能页把背景压暗并模糊 10px，卡片改成半透明
毛玻璃，星空退回背景。海报上的轨道线仍由 Canvas 绘制，叠在真实星空之上；画布不再画星点，
因为照片里已经有了。

图片按 `background-size: cover` 铺满，屏幕比例不同会裁掉左右边缘，右下角的「豆包AI生成」
水印在窄屏上通常会被裁掉、在宽屏上可能露出。要固定保留或固定去掉，改
`.bg-layer` 的 `background-position` 即可。

## 三种权限，都在本机

- **系统通知** — 允许后到点推到锁屏。必须由你点击按钮触发，浏览器不接受自动请求。
- **声音与振动** — 手机浏览器要求先有一次用户点击才允许发声，所以做成「试听」按钮。
- **屏幕常亮** — 用 Screen Wake Lock API，在有待命提醒时阻止息屏。可选，部分浏览器不支持。

## 离线使用

闹钟逻辑本来就零外部请求（系统字体、图片全内嵌、数据存本机），下载单个
`index.html` 双击打开，从第一秒起就不需要联网。

如果你是通过网址访问（GitHub Pages 或自己的服务器），目录里另外放了
`manifest.webmanifest`、`sw.js` 和四个 `icon-*.png`，让浏览器可以把它
**装成一个 App**：

- **Android / 桌面 Chrome** — 打开网址后地址栏或菜单里会出现「安装」/「添加到主屏幕」，
  装一次即可，图标是深空信标那个轨道点标记。
- **iPhone** — Safari 打开网址 → 分享 → 添加到主屏幕。
- 装上、或哪怕只是完整打开过一次之后，Service Worker 会把页面、图标都缓存到本机。
  **之后断网重新打开这个网址也能用**，计时、写提醒、响铃全部照常，因为本来就没有
  任何逻辑依赖网络——缓存解决的只是「第一次得连得上网才能拿到这个页面」这一步。
- 单独打开 `index.html` 本地文件时，浏览器不支持在 `file://` 下注册 Service
  Worker，这两行请求会静默失败，不影响闹钟本身——本来就不需要它。
- 改了 `index.html` 之后要更新已安装用户的缓存，把 `sw.js` 里的 `VERSION`
  常量加一，浏览器才会去换一份新的，不然装过的人会一直停在旧版本。

## 已知限制（请务必知道）

网页闹钟靠这个页面自己计时：

- **页面被完全关掉（不是断网）就不会响。** 留在前台或后台标签页 / 已安装的 App 里，别划掉。
- **iPhone** 需要先「添加到主屏幕」，从主屏图标打开才能收到系统通知（iOS 16.4+）。
- **嵌在 iframe 里时无法申请通知权限**，浏览器只允许顶层窗口申请。页面会检测到并提示你在独立标签页打开。
- 系统长时间挂起标签页时会延迟触发；页面回到前台会立刻补发，并标注「错过的信标」。
- 重要的事情，请同时设一个系统自带闹钟。

## 部署

1. **GitHub Pages** — 仓库 Settings → Pages → Source 选 `main` 分支、`/docs` 目录，
   保存后访问 `https://echo844883.github.io/skills/beacon/`。手机上用这个地址最省事，
   而且能装成离线可用的 App（见上）。
2. **本地文件** — 下载 `index.html`，用任意浏览器打开。不需要其余文件，闹钟功能完整；
   只是不会出现「安装到主屏幕」的入口。
3. **自己的服务器** — 把 `docs/beacon/` 整个目录丢进任何静态托管即可，保留全部文件
   才有离线安装能力；只想要闹钟本身的话，单传 `index.html` 也够用。

## 数据

存在浏览器的 localStorage（键名 `beacon.reminders.v1`），跟着「设备 + 浏览器」走，
不上传任何地方。清缓存或换设备会丢失。

## 自检

打开 `index.html?test=1`，控制台会跑 13 项断言：重复规则的时刻推算（含「时刻恰好
等于当前」不得原地重复触发、跨星期顺延、未选星期退化为每天）、倒计时文案、页面与
点位数量一致、响铃层按钮不换行、文档不横向溢出。
