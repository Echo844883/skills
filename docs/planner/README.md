# 课程排程台（独立版）

`index.html` 是一个完全自包含的单文件应用：没有任何外部请求，没有构建步骤，
双击就能用。为在无法访问 Google Fonts 的网络环境下正常显示，字体全部使用
系统字体栈。

## 三种用法

1. **GitHub Pages** — 仓库 Settings → Pages → Source 选 `main` 分支、`/docs`
   目录，保存后访问 `https://echo844883.github.io/skills/planner/`。
2. **本地文件** — 下载 `index.html`，用任意浏览器打开。数据存在该浏览器里。
3. **自己的服务器** — 把这一个文件丢进任何静态托管即可。

## 数据存哪

存在浏览器的 localStorage 里，跟着「设备 + 浏览器」走，不上传任何地方。
换设备或清缓存前，用「导出」把 JSON 存下来，到新设备用「恢复备份」读回。

微信内置浏览器会较激进地清理站点数据，**重要计划请定期导出备份**。

## 与 Artifact 版的差别

Artifact 版多一个「云端保存」按钮（把数据写回页面自身，跨设备同步）和文件
下载能力。独立版检测不到这些运行时能力，会自动隐藏云端按钮，并把导出降级
为可复制的 JSON 文本。其余功能完全一致。
