# 信标提醒台（课程排程台配色版）

`index.html` 是 [`../beacon/`](../beacon/) 那个网页闹钟的另一套皮肤：同样的计时、
权限、响铃逻辑，视觉换成了跟 [课程排程台](https://echo844883.github.io/Claude-/)
同一套设计系统——松石绿为骨、杏橙为触发状态、卡片+侧栏的桌面优先布局、浅色为主、
深色随系统自动切换。两个版本读写同一个 localStorage 键（`beacon.reminders.v1`），
在同一个浏览器里打开哪个都能看到同一份提醒。

## 和深空版的区别

| | `beacon/`（深空遥测） | `beacon-planner/`（本页） |
| --- | --- | --- |
| 视觉 | 深色单一主题，Canvas 轨道、星空背景 | 浅色为主，随系统深色，卡片+侧栏 |
| 结构 | 四屏横向翻页 | 单页仪表盘：顶部统计条 + 侧栏 + 队列 |
| 新建/响铃 | 全屏层 | 原生 `<dialog>` 弹窗 |
| 功能 | 完全一致：时刻、自定义内容、仅一次/每天/按星期、通知、声音、屏幕常亮、离线 PWA | 同左 |

## 界面

顶部一条统计栏：已武装数量、下一次触发、通知权限状态，右侧「发测试通知 / 清空队列 /
新建提醒」。左侧栏是「授权」（通知、声音、屏幕常亮，逐项请求）和「说明」；右侧主区是
「待命队列」，每条提醒左边一条色带（六种颜色轮转，呼应课程排程台的课程色）、居中
mono 大字时刻、消息、重复方式与实时倒计时，右边启停/删除。

「新建提醒」和到点的响铃都用原生 `<dialog>`：時刻、提醒内容、重复方式（仅一次 / 每天 /
按星期，胶囊分段控件）、按星期时展开的星期选择行。

## 离线使用

跟深空版一样：`index.html` 本身零外部请求（系统字体、无图片依赖、数据存本机），
下载单个文件双击打开就不需要联网。托管访问时另外带了 `manifest.webmanifest`、
`sw.js` 和四个 `icon-*.png`（沿用课程排程台品牌标记：白色卡片上一枚旋转的
松石绿→杏橙渐变方块），装到主屏幕或完整打开过一次后，断网重开这个网址也能用。
改了 `index.html` 记得把 `sw.js` 里的 `VERSION` 加一。

## 已知限制

和深空版相同：页面被完全关掉就不会响；iPhone 要先添加到主屏幕才能收到系统通知；
嵌在 iframe 里无法申请通知权限；重要的事情请同时设系统自带闹钟。详见
[`../beacon/README.md`](../beacon/README.md)。

## 自检

打开 `index.html?test=1`，控制台跑 12 项断言（时刻推算、倒计时文案、侧栏卡片数、
新建/响铃均为原生 dialog、文档不横向溢出）。
